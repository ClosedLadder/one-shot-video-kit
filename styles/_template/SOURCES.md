# SOURCES — styles/_template/

**Built** 2026-09-24 for the one-shot video kit (not vendored).

- `STYLE.md` — the style-pack contract. Strict superset of the sections in
  `styles/watercolor-cartoon/STYLE.md` (the kit's Style A): every section of the
  existing pack maps into the template; the template adds the sections the
  existing pack keeps implicit — Typography rules, Character & prop conventions,
  Shot grammar, Pipeline feasibility, Example AI-footage prompts, Asset inventory,
  Changelog. (The existing pack is not edited to match; sections that don't apply
  to a style are answered in one line, e.g. "typography banned — see The look.")
- `assets/ASSETS.md` — the seven asset-slot spec (palette.png, 2 model sheets,
  3 example frames, optional texture). Slots are filled only from real renders.
