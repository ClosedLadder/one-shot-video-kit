# TTS — voice selection and audition

No API keys in this repo. Configure voices on the machine that renders.

## Procedure (before locking a voice for a style)

1. Write 2–3 short audition lines from the brief (include direction tags like `[warm, unhurried]`).
2. Generate each candidate voice at the target tier's budget (`tiers/STUDIO.md`, `tiers/BEST.md`).
3. Score against the scoreboard's **Audio sync** dimension (`scoreboard/rubric.md`).
4. Record the winner here: voice id, provider, direction baseline, and the run id that proved it.
